## Sobre o projeto

O **Julia de bolso** é o meu cantinho pessoal na web — um site feito do zero para treinar HTML, CSS e JavaScript enquanto crio algo com a minha cara. A ideia é ter um espaço leve, bonito e com navegação simples, parecido com um app, onde eu guardo desde anotações até uma galeria de imagens.

## Páginas

- **Home** — página inicial de entrada do site;
- **Galeria** — espaço com imagens organizadas;
- **Notas** — anotações pessoais;
- **Músicas** — lista/curadoria de músicas;
- **Conversor ASCII** — ferramenta que transforma imagens em arte de texto.

## Conversor de imagens em ASCII

Um dos destaques do projeto é o meu conversor de imagens em ASCII (`ascii.html`), feito com JavaScript puro. Ele permite:

- Fazer upload de qualquer imagem direto no navegador;
- Converter a imagem em arte ASCII (texto) com base na tonalidade dos pixels;
- Visualizar o resultado na hora, sem precisar de backend ou instalação.
